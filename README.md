# Moa Economy v1.3

- 공부 영역과 하단 편집 바 너비를 1160px로 통일 (모바일 자동 조절)
- 체크한 문장의 편집 바만 접기/펼치기, 문장 본문은 유지
- 문장 나누기 가위는 문장부호와 다음 문장 시작이 확인되는 지점에만 표시, 수동 나누기 제공
- 숫자 소수점과 일부 약어가 자동 분리되지 않도록 분리 로직 개선
- BBC 기사 URL 입력/저장 및 기사 원문 열기, 달력에서도 원문 열기
- BBC RSS 뉴스가 없더라도 BBC Business 링크 항상 표시
- 구글 번역과 BBC 창은 작은 팝업을 요청하지만 iPad Safari에서는 새 탭으로 열릴 수 있음
- 기존 localStorage 키 moa-economy-v1 유지

업로드 전 반드시 JSON 백업을 내려받으세요. 화면 업데이트만 필요하면 index.html만 저장소 최상위에 교체하세요.
